The patch adds Emscripten event-loop timers, cooperative Asyncify yielding,
lazy music decoding, touch input, latched brief key presses, persistent-save
notifications, portable text map loading, and a corrected Continue wait loop. Desktop functionality remains
conditionally compiled. Browser saves use a namespaced IDBFS mount.

BUILD / RELINK
1. Clone the pinned source into a directory called wizball-web-source.
2. Apply source-port.patch there with git apply.
3. On a case-insensitive disk, restore the original Fortify headers:
   git show HEAD:wizball/FORTIFY.H > wizball/fortify.h
   git show HEAD:wizball/UFORTIFY.H > wizball/ufortify.h
4. First build natively with CMake (Release, WIZBALL_PORTMASTER=OFF), then build
   its wizball_data_zip target to generate scripts and other game data.
   Native dependencies: SDL2, SDL2_image, SDL2_mixer, CMake, C++ compiler.
5. Create sibling wizball-browser/dist/ and package the full generated data:
   python3 tools/package_data_zip.py --root . --output ../wizball-browser/full-data.zip
   Then run the provided browser tools (paths below relative to this file):
   python3 tools/stage_web_assets.py --source /path/to/full-data.zip --output /path/to/wizball-browser/dist
   This creates data.zip for startup, hashed deferred ZIPs, and staged-assets.json.
   The browser uses text maps rather than native pointer-bearing map caches.
6. Activate Emscripten 6.0.13 and run:
   emcmake cmake -S wizball-web-source -B build-web -DCMAKE_BUILD_TYPE=Release -DWIZBALL_PORTMASTER=OFF
   cmake --build build-web -j6
7. Copy generated wizball.js, wizball.data and wizball.wasm into the staged dist
   folder, then run:
   python3 tools/split_web_assets.py --directory /path/to/wizball-browser/dist
   Publish the shell, wizball.js, build.json and its referenced engine, asset
   chunks and deferred ZIP files. Raw .data/.wasm/data.zip are not published.
8. Serve over HTTP(S). The page must be clicked to start, allowing browser audio.

All library modifications can be rebuilt and relinked using the Emscripten
ports toolchain. The used mpg123 source is included in licenses/; the SDK's
ports recipes provide the other upstream library sources. Licence notices
are in licenses/ and credits.txt.

Hosting: a static Cloudflare Worker handles only /wizball and /wizball/*.
Other paths on tonyclancy.com use the pre-existing website.

Physical gamepads and mobile devices require hands-on verification; the
browser wrapper includes defaults and touch controls. Progress is local to
one browser profile and is not synchronized between devices.
